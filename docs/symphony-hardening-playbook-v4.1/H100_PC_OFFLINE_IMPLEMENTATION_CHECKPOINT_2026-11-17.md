## Implemented controls and their limits

C01 synchronizes a one-use allowance before worker spawn, bound to the exact
project, Plane item, Planner responsibility, source/configuration and RuntimeAttempt
lineage. AgentRunner synchronizes a separate launch claim before workspace use.
Ordinary retry, continuation, route change, another role, another item, counter
reset or configuration removal cannot reopen consumption. Startup quarantines a
consumed/running prior attempt without stop proof. Gate 2 binding history cannot
be downgraded into the legacy pilot boundary.

C03 uses one absolute monotonic deadline for launch, session setup, the turn and
stopping. Incoming output does not reset it. There is no default pilot entitlement
or default approved 120-second budget. Deadline-bearing pilot stops require the
captured namespace PID1 identity and observed death plus outer-port death. Missing
proof retains the fence, workspace and session home. Ordinary routed sessions
without a pilot deadline retain their established guarded-stop behavior.

C04 persists only the permitted final Planner answer and allowlisted correlations
in the durable attempt ledger. It binds project/item, RuntimeAttempt/role,
source/configuration, available session/thread/turn IDs, model state, outcome and
stop disposition. Completion requires synchronized final evidence after required
stop proof. Raw protocol logs are excluded. Oversized, contradictory, ambiguous or
recognized credential-bearing results refuse completion or quarantine; this is
not a claim to detect every possible secret encoding.

F01 binds exact Planner-policy bytes and the effective role-prompt root into the
pilot authority identity. Launch uses the validated bytes and refuses drift or
missing policy. The shipped Planner instructions are unchanged. F02 binds trusted
absolute `/usr/bin/git`, ancestry and SHA-256. F03 isolates Git environment selectors,
binds the canonical worktree and hashes actual tracked contents, symlink targets,
types and executable modes independently of index flags. No index repair or
checkout cleanup occurs at admission.

C02 binds the same consumed grant and RuntimeAttempt to holder/profile, host
permission/registration, host/boot identity, immutable generation and lifetime
budgets. Its signed readiness/disposal receipts are synthetic test interfaces.
Production refuses `siwc_planner_pilot_v1` while native dependencies are unavailable.
Non-test NativePilot builds contain no native execution helpers. No operational
materialization adapter, receipt producer or enrollment API is implied.

The native host/bootstrap and actual patched Codex execute locally with synthetic
material. The host alone generates it after the guard forks. The bootstrap closes
its materialization channel and unapproved descriptors, then executes the sealed,
hash-verified ELF with explicit fresh HOME/CODEX_HOME. The guard never receives
material. No credential file, command argument or generic Symphony RPC carries it.
Same-UID synthetic observations are not qualified host custody or UID/LSM separation.

The actual standalone app-server takes its early protected entry before generic

selected profile/binding/attempt/deadline, descriptor set and private fresh homes.
It applies core/dumpability, no-new-privileges and Linux x86_64 seccomp controls,

## Lifecycle, guards and terminal dispositions

C01 states are `configured`, `consumed`, `running`, then `stopverified` or
`quarantined`. Durable write and sync are guards for consumption, launch and final
result transitions. Uncertain persistence refuses the next operation and keeps
applicable consumption/fences. Terminal records cannot be overwritten or rearmed
through ordinary runtime operations. These are the existing attempt authority,
not a new native attempt identifier.

The C02 test interface progresses through `selected`, `launch_ready`, `thread_ready`,
`turn_ready` and `disposed`. Every forward operation rechecks grant, current
source/policy/configuration, profile and deadline. Receipts require the pinned
synthetic signer, full binding, fresh challenge, durable reference and valid
lifetimes. Turn permission is one-use. Refusal blocks progression. Disposal uses
the original binding after independent stop, including revoked forward authority.
Expired or missing disposal retains the home and quarantined disposition.

Native journal observations are subordinate to that same RuntimeAttempt:

1. `HOST_PERMISSION_VALIDATED` requires the selected private permit, binding,
   attempt, guard PID/start, executable hashes and unexpired deadline.
2. `BOOTSTRAP_CREATED` records one fork before delivery. No retry is available.
3. `MATERIALIZATION_INTENT` requires peer/process/topology checks and an exclusive,
   file-and-directory-synchronized consumption marker before possible delivery.
4. `SYNTHETIC_MATERIALIZED` records the one delivery. Partial delivery or uncertain
   journaling retains consumption and ambiguity/quarantine.
5. `CREDENTIAL_CHANNEL_CLOSED` requires independently observed EOF and a synchronized
   marker before the guard accepts readiness.
6. `HOLDER_READY` establishes synthetic process controls, not authentication.
   The real Codex path next records `CODEX_INITIALIZED_NOT_AUTHENTICATED`.
7. `INFERENCE_INTENT` is synchronized before the synthetic request. The current
   real-Codex request is `thread/start`, which refuses. `INFERENCE_REFUSED` records
   controlled refusal; no provider call or inference follows. Ambiguous fixture
   effects cannot become model success.
8. `TERMINATION_REQUESTED` targets only the exact unreaped child. `GUARD_REAPED`
   requires waitpid; independent host pidfd death establishes
   `TERMINATION_VERIFIED`. Outer-port death alone proves neither pilot containment
   nor native disposal.
9. `DISPOSAL_VERIFIED` requires both stop observations and controlled refusal in
   this synthetic process/channel scope. It is not full P08 disposal qualification.
   Missing observation, cleanup failure, uncertain delivery, deadline or crash
   enters `QUARANTINED` and retains the consumption marker and evidence.

Parent-death signals, parent identity rechecks and the absolute deadline limit
this fixture. Restart refuses the existing consumption marker; it does not restore
materialization or retry possible effects. Synchronized binding/correlation files
must exist before C02 returns controlled refusal. C04 retains a noncompleted
attempt result. Local process death never proves remote provider cancellation or
